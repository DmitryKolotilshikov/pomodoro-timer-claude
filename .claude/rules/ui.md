# Правила для вёрстки и стилей

- Цвета только через CSS-переменные в `:root`, без хардкода в правилах.
- Все стили в одном блоке `<style>` в `index.html`, inline-атрибутов `style=""` не писать.
- Размеры в `rem`, `px` только для рамок и теней.
- Кнопки одной высоты, скругление 8px, обязательно состояние `:hover`.
- Никаких CSS-фреймворков и внешних шрифтов — только системный шрифт.
